# 🚀 RocketAir  

**RocketAir** is a modern animated website showcasing cutting-edge web development techniques. It leverages powerful tools to deliver a smooth and visually stunning user experience.  

## 🌟 Features  
- **Smooth Animations**: Powered by GSAP for seamless motion effects.  
- **Advanced Scrolling**: Implemented with Locomotive Scroll for next-level user interaction.  
- **Responsive Design**: Built with HTML, CSS, and JavaScript for compatibility across devices.  

## 🛠️ Technologies Used  
- **GSAP (GreenSock Animation Platform)**  
- **Locomotive Scroll**  
- **HTML5, CSS3, JavaScript (ES6)**
